# DESIGN — Sentits Quest · «Àlbum de cromos»

Mateix sistema que Vascular Quest (vegeu-ne el DESIGN.md): coberta indigo `#22194d`, pàgina groga `#f2b42c` amb trama, cara blanca `#fffdf8`, daurat `#ffd86b`, Big Shoulders Display + Atkinson Hyperlegible, cromos amb vora retallada, forats discontinus, sobre d'instruccions amb vídeo i moviment de `fx.js` sense canvis.

## Canvis respecte de l'original

| Element | Vascular Quest | Sentits Quest |
| --- | --- | --- |
| Color de sistema | artèria `#d7263d` · vena `#1f5fbf` | ull `#0b7a83` (turquesa) · orella `#b1500f` (coure) |
| Làmina | imatge 2D amb zoom | model 3D (three.js) dins la làmina blanca; es gira arrossegant el fons |
| Forats | posició fixa de la clau | dues columnes que segueixen l'alçada projectada del punt, sense solapaments |
| Punt | imprès a la làmina | punt negre amb vora blanca; discontinu si queda a l'altra cara del model |
| Fase 3 | mapa mut (escriure) | text amb buits i desplegables de 3 opcions |
| Lliurament | correu al professor | PDF a la tasca de Google Classroom |
| Idioma | català | català o castellà, triat a l'entrada amb banderes (senyera i bandera d'Espanya sense escut) |
| Informe | punts | nota de 1 a 10 al bloc principal (coberta indigo, xifra daurada), nota per fase i fórmula |
| Línies guia | rectes | en colze, acabades al centre exacte d'un punt de precisió (anell fosc amb centre blanc) |
| Moviment 3D | — | entrada de càmera (1,3 s), il·luminació daurada de l'estructura encertada (1,1 s); res amb moviment reduït |
